# Morph 1.12.2 — способности и поведение мобов

Форк [JartiX/Morph](https://github.com/JartiX/Morph), основанный на [iChun/Morph, ветка 1.12.2](https://github.com/iChun/Morph/tree/1.12.2), основание `4452af4a9f53c8a61eaf2b86c7fb2777e71316c8`. Лицензии исходного проекта сохранены: COPYING и COPYING.LESSER.

- **R** — способность текущего моба; клавиша переназначается в управлении. Сбоку от хотбара расположен один ванильный слот: значок действия и оставшиеся секунды. Название кратко появляется при смене формы с пустой рукой.
- **[ / ]** — выбор формы; Shift переключает варианты, Enter подтверждает.
- Все 50 ванильных живых форм имеют действие. Боссы разрешены настройкой `bossMorphs=1` по умолчанию.
- Сервер проверяет способность и хранит кулдауны между сменами формы, смертью и входами. Клиент и сервер должны использовать одну версию этого ответвления, 7.3.1.
- Враждебный облик скрывает от монстров до провокации. Хищники, добыча и страх учитывают форму; удар волка-морфа по неигровой цели привлекает свободных диких и своих волков.
- У каждого действия есть ванильный звук; попадания снарядов озвучиваются отдельно. Неудачное действие даёт тихий личный отклик без звука успешного применения.
- POV использует настоящую геометрию и текстуру конечности, закреплённую у края экрана; стандартное движение предметов и замах сохраняются.

## Установка

Minecraft **1.12.2**, Forge **14.23.5.2847** (версия стенда), **iChunUtil 7.2.2**. Удалить другой Morph той же установки, положить `Morph-1.12.2-7.3.1.jar` в `mods` клиента и сервера. iChunUtil не включён внутрь jar: его необходимо установить отдельно из [официального выпуска](https://www.curseforge.com/minecraft/mc-mods/ichunutil/files/2801262).

Настройки прежнего Morph сохраняются. При обновлении существующей установки при необходимости включить `bossMorphs=1` вручную. Новая кнопка находится в категории Morph.

Таблицы пассивных свойств загружаются из jar до входа в мир, интернет не требуется. Пользовательские локальные/удалённые таблицы остаются отдельной явной настройкой.

Крипер тратит 4 HP, остаётся минимум 1 HP; блоки разрушаются согласно `mobGriefing` и Forge-событиям защиты. Паутина удерживает цель эффектом, без постоянных блоков. Курочка сносит предмет яйца. Способности модовых существ не добавляются. Торговый интерфейс NPC, размножение, разрушение блоков телом босса и прохождение вредины сквозь стены не копируются.

## Сборка

Требуются **JDK 21** для Gradle и **JDK 8** для Minecraft. Gradle 8.14 и RetroFuturaGradle 1.4.9 закреплены; iChunUtil загружается автоматически. Gradle обнаруживает обычные установки Java; при необходимости указать `JAVA8_HOME` либо `-Porg.gradle.java.installations.paths=<путь к JDK8>`.

```powershell
$env:JAVA_HOME = '<путь к JDK21>'
$env:JAVA8_HOME = '<путь к JDK8>'
.\gradlew.bat build
```

Готовый устанавливаемый jar находится в `build/libs/`. `*-sources.jar` — исходники.

```powershell
.\gradlew.bat runClient -Pvalidation
```

Флаг validation включает отдельный тестовый мод: он создаёт собственный мир, проводит серверные проверки и снимает framebuffer игры. В обычную сборку этот мод не входит. Для обычной игры из среды разработки: `runClient` без флага.

Небольшой coremod сохраняет ванильные свойства нежити/членистоногих (зелья, чары) и иммунитет пауков к паутине. Исходные реализации остальных существ не подменяются. Совместимость с другими coremod и защитой территорий требует проверки на конкретной сборке.
